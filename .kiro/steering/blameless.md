# Blameless rules (Nadya Bartol, TED@BCG 2021)

- Owners come from CODEOWNERS only. NEVER use git blame or surface the commit authors of vulnerable code.
- Rot is attributed to the limb (package), never to a person.
- Messages name people only in praise ("healed by"), never in failure.
- UI copy states actions to take, never prohibitions.

Property test: no output ever contains a commit author associated with a vulnerable line.
