## High-level view

The seed now follows "unknown stays unknown". Mean time to heal reads `unknown` for lodash because the Healed line carries no time. The 3-minute PR-open-to-merge figure is shown as a separate "time to land", and age is labelled as counting from the first history line, which in the seed is the fix PR opening.

One run now adds one point. Lines of the same limb closer than 5 minutes are treated as one run, which removes the autopsy plus gazette duplicates. The window is a heuristic, not a run id.

Deadlines start from the creature's found time when it has one, then from the earliest recorded deadline, then from the current run. Long-open KEV limbs no longer get a fresh 48-hour window, as long as the creature carries a found time.

## Five-minute run window

`RUN_WINDOW_MS` is a time heuristic, not a run identity. The cost is that a real transition inside the window is overwritten, and lines from two separate runs less than 5 minutes apart look like one. For daily or per-push runs this is harmless. A single run timestamp passed by the action would remove the guess (possible, low impact).
