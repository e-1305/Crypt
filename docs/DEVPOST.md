# Devpost entry notes

**Live demo:** https://e-1305.github.io/Crypt/

**Tagline:** The first vulnerability report you can play.

**What to open:** the page loads a demo creature with no setup. Type `GRAFT JQUERY` to read the dry-run pull request payload. "Download the playable report" saves the story file for any Z-machine interpreter. The gallery lists 20 public projects alphabetically, each with its own creature.

**Source:** https://github.com/e-1305/Crypt

**Safety:** the page only reads its own files and sends nothing. A graft there is a rehearsal. In the CLI, a person lands every pull request.
