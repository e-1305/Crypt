# CRYPT security audit: the 15 common vibe-coded app issues

Audit date: 2026-11-19. Commit audited: `299b7ad` (`main`). Scope: this repository (CLI, GitHub Action, workflows, static site in `web/`). This pass changes no code. Fixes are listed at the bottom as small follow-up items.

How it was done: read the code at each place named below, searched the tree and git history for the patterns, ran `npm audit` against `package-lock.json`, and measured the two regular expressions flagged in items 10 and 11. Line numbers refer to the commit above.

Severity scale: **High** means a remote attacker can steal data or run code. **Medium** means a plausible failure or abuse path with real impact on users or the release pipeline. **Low** means hardening or a gap that needs an unusual input. Severity is given for FAIL rows. PASS rows show `-`.
