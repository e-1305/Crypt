## Judging criteria

Source: https://kiroween.devpost.com/rules, section 6 "Judges & Criteria".

Stage One is pass/fail: "the Project reasonably fits the theme and reasonably applies the required tools". Stage Two uses "the following equally weighted criteria", each 20% (10 points):

| Criterion | One-line description |
| --- | --- |
| Potential Impact | "Does the project make a credible case for solving a real problem for a real audience?" |
| Technological Implementation | "How thoroughly and skillfully does the project use Kiro?" |
| Design | "Does the project deliver a complete, coherent product experience, not just a technical proof of concept?" |
| Innovation/Idea | "How creative and novel is the concept, and does the project differ from existing concepts?" |
| Presentation | "Does the video clearly demonstrate the project working end-to-end?" |

Tie break: tied entries are re-scored "using a 20-point scoring maximum for each criterion".

## Video rules

Source: https://kiroween.devpost.com/rules, section 4 "Project Requirements".

- Length: "should be less than three (3) minutes. Judges are not required to watch beyond three minutes".
- Content: "should include footage that shows the Project functioning on the device for which it was built".
- Hosting: "must be uploaded to and made publicly visible on YouTube" with the link on the submission form.
- Rights: "must not include third party trademarks, or copyrighted music or other material unless the Entrant has permission".
- Language: non-English material needs an English translation.

## Other submission requirements worth watching

Source: https://kiroween.devpost.com/rules, section 4 "Project Requirements".

- Code: "public URL to your code repository on GitHub (NOT GitLab or BitBucket)" with a detectable open source license.
- Kiro usage: "Your repo must contain the /.kiro directory at the root". Never add `/.kiro` to `.gitignore`.
- Team size: maximum 3 participants per team.
- Latest eligibility change: residents of Australia added (rules updated November 16, 2026).
