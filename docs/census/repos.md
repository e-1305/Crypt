# Census repositories

Twenty public projects scanned by `npm run census`: 10 npm projects with a root `package-lock.json` (v2 or v3) and 10 Python projects with a root `requirements.txt` that has `==` pins. Sizes range from a handful of pins to thousands of locked packages.

Each repository is read **only at the commit SHA below** (root manifests and CODEOWNERS files, as text). No code is run and nothing is installed. To change the sample, edit this table; the parser reads rows whose first cell is `npm` or `PyPI`.

Results are published as aggregates only, in [RESULTS.md](RESULTS.md).
