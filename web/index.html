CRYPT

The first vulnerability report you can play

Each vulnerable dependency is a limb on a creature, and you heal it by typing GRAFT, which writes a fix pull request for a human to review and land.

Try it on your own repo: npx @e-1305/crypt raid <path-or-github-url>

Built with Kiro: specs, steering and hooks

How to play (manual) Plain text, no effects, game events announced.

SEALED: no graft will run.
